# Simple-Notepad
A simple Notepad web application built using HTML, CSS, JavaScript, and Bootstrap. Users can write notes, save them, edit existing notes, and delete notes.
# Features
Create new notes
Display saved notes
Edit notes
Delete notes
Responsive Bootstrap interface
Simple and user-friendly design
# Technologies Used
HTML5
CSS3
JavaScript (DOM Manipulation)
Bootstrap 5
# Project Structure
index.html – Main webpage
styles.css – Styling
note.js – Application logic
